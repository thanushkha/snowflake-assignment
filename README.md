# Snowflake Assignment

## 📌 Overview

This repository contains my **Snowflake Tutorial Assignment** completed using **Snowflake Notebooks**.

The assignment covers Snowflake object creation, SQL operations, data loading, Time Travel, and data recovery.

## 🛠️ Technologies Used

- Snowflake
- Snowflake Notebooks
- SQL
- SnowSQL

## 📚 Questions Covered

### 1. SnowSQL Login and Connection

- Verified the Snowflake connection
- Displayed:
  - Current User
  - Current Role
  - Current Warehouse
  - Current Database
  - Current Schema

### 2. Creation of Snowflake Objects

Created the following Snowflake objects:

- Database
- Schema
- Warehouse
- Table
- Stage

Performed basic SQL operations:

- SELECT
- INSERT
- UPDATE
- DELETE

### 3. Data Loading Using SnowSQL

- Created a sample customer dataset
- Loaded the data into a Snowflake table
- Verified the loaded data using SQL queries

### 4. Snowflake Time Travel

Demonstrated Time Travel by:

- Creating a table
- Inserting sample records
- Updating records
- Deleting records
- Retrieving the earlier version of the table

### 5. Data Recovery Using Time Travel

Demonstrated recovery of accidentally deleted records using Time Travel.

Steps performed:

1. Created sample records
2. Saved the timestamp before deletion
3. Deleted records
4. Identified deleted records using Time Travel
5. Recovered the deleted records
6. Verified the recovered data
